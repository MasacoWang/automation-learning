The Basics

Code
Instructions you write for the computer. Like a recipe — step 1, step 2, step 3.
Script
A file containing code. You press "Run" and it does the work.
VS Code
The app where you write your scripts. Like Microsoft Word, but for code.
Terminal
A text-only chat with your computer. You type commands, it replies. Lives inside VS Code.
Python
A programming language. The simplest one to learn. Your scripts will be in Python.
Variable
A container that holds information. Like a name tag — name = "Sarah" stores "Sarah" so you can use it later.
String
Text in code. Always wrapped in quotes: "Hello World"
Function
A reusable set of instructions. Like a saved email template — define it once, use it many times.
Loop
Repeat something. "For each candidate in my list, send an email." That's a loop.
CSV file
A spreadsheet saved as plain text. Excel can save files as .csv. Python loves reading these.

Tools & Actions

Git
A "save game" system for your code. It remembers every version so you can undo mistakes.
GitHub
A website that stores your code online. Like Google Drive but for code projects.

AI that writes code for you. You describe what you want in English, it writes the code. You already have it!
Package / Library
Code someone else already wrote that you can use for free. Like pre-made ingredients.
pip install
The command to download a package. Like "Add to cart" for free code tools.
Run / Execute
Tell the computer to follow your instructions now.
Bug
A mistake in your code. Everyone gets them. Google the error message to fix it.

Finding and fixing the bug. Detective work!

✨ Your First Project: Email Generator

In 10 minutes, you'll build a tool that writes 50 personalized emails instantly.

📬 What we're building

The problem: You have 50 candidates. You need to send each one a personalized email. Doing it manually = 2 hours of copy-paste.

The solution: Write a template once + give it a list of names → it generates all 50 emails in 2 seconds.

Step 1: Create a new file

1

Open VS Code

2

Press Ctrl + N (new file)

3

Press Ctrl + S to save it. Name it: email-generator.py

Why .py? The .py at the end tells the computer "this is a Python file." Just like .docx means Word document.

Step 2: Write the code

Copy and paste this into your file:

# This is my email generator!
# Lines starting with # are notes (computer ignores them)

# --- MY CANDIDATE LIST ---
candidates = [
    {"name": "Sarah", "role": "Software Engineer"},
    {"name": "James", "role": "Product Manager"},
    {"name": "Lisa", "role": "Data Scientist"},
]

# --- MY EMAIL TEMPLATE ---
template = """Hi {name},

I saw your profile and loved your experience as a {role}.

We have a role that's a great fit for your background.
Would you be open to a quick 15-min chat this week?

Best,
Clarice"""

# --- GENERATE EMAILS ---
for person in candidates:
    print("─" * 40)
    print(f"TO: {person['name']}")
    print("─" * 40)
    email = template.format(
        name=person["name"],
        role=person["role"]
    )
    print(email)
    print()

Step 3: Run it!

→

Open Terminal: Ctrl + `

→

Type this and press Enter:

python email-generator.py

🎉 You just automated email generation!

Step 4: Make it yours

Now customize it! Try changing:

  • Add more candidates to the list
  • Change the email template text
  • Add more fields like "company": "Google"
💡 How Copilot helps: In VS Code, type a comment like # add the candidate's company to the email and Copilot will suggest the code change for you!

🐍 Your First Automation Script

Let's build an email generator that personalizes outreach from a candidate list.

Step 1: Install Python

  1. Go to python.org/downloads
  2. Download latest version
  3. Important: Check ✅ "Add Python to PATH" during install
  4. Verify: Open terminal → type python --version

Step 2: Create email-generator.py

# My first automation script!
# Generates personalized outreach emails

candidates = [
    {"name": "Sarah", "role": "Software Engineer", "company": "Google"},
    {"name": "James", "role": "Product Manager", "company": "Meta"},
    {"name": "Lisa", "role": "Data Scientist", "company": "Amazon"},
]

template = """
Hi {name},

I came across your profile and was impressed by your
experience as a {role} at {company}.

We have an exciting opportunity that aligns with your
background. Would you be open to a brief chat this week?

Best regards,
Clarice
"""

for candidate in candidates:
    email = template.format(**candidate)
    print(f"--- Email for {candidate['name']} ---")
    print(email)

Step 3: Run it!

python email-generator.py

🎉 You just automated email generation!

Step 4: Level up — Read from CSV

Create candidates.csv:

Name,Role,Company
Sarah,Software Engineer,Google
James,Product Manager,Meta
Lisa,Data Scientist,Amazon

Updated script:

import csv

template = """Hi {name},
I was impressed by your experience as a {role} at {company}.
Would you be open to a brief chat?
"""

with open('candidates.csv', 'r') as file:
    reader = csv.DictReader(file)
    for row in reader:
        email = template.format(
            name=row['Name'],
            role=row['Role'],
            company=row['Company']
        )
        print(email)
💡 Key concept: A variable like {name} is a placeholder that gets replaced with real data. That's the core of all automation — templates + data = personalized output.

# 📋 Interview Feedback Daily Summary

A zero-setup bookmarklet that extracts interview feedback from TA Hub with one click.

## How It Works

1. **Drag** the bookmarklet to your bookmarks bar (one-time)
2. **Open** TA Hub → any requisition → Feedback tab
3. **Click** the bookmark → summary is copied to clipboard + popup with email option

## Features

| Feature | Description |
|---------|-------------|
| ✅ Zero Install | Just a bookmark — no extension, no app, no admin approval |
| 📊 Auto-Extract | Reads interviewer names, decisions (👍/👎), form types, dates |
| 📋 One Click Copy | Summary instantly copied to clipboard |
| 📧 Quick Email | Opens pre-filled Outlook email with summary |
| 🔒 Secure | Runs locally in browser, no data sent anywhere |
| 🏢 Org-safe | No extension install = no IT approval needed |

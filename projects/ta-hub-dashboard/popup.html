📊 TA Hub Dashboard

✅ Active — Dashboard is showing on TA Hub

This extension adds a floating dashboard on TA Hub pages that shows:

  • Pipeline stage counts
  • Feedback status per interviewer
  • Candidates needing action
  • Dispose/continue recommendation
How to use:
  1. Go to TA Hub
  2. Open any requisition
  3. Dashboard appears on the right side
  4. Click into candidates to see feedback details
